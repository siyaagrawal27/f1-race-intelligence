# Project Summary

## Title
Formula 1 Race Intelligence Analysis

## Problem statement
Formula 1 race data spans drivers, constructors, circuits, seasons, and race outcomes. This project aims to organize relevant data into interactive visualizations so viewers can compare performance and investigate patterns.

## Intended users
- F1 team performance strategists
- Motorsport journalists and broadcast analysts
- Technical and reliability analysts
- Formula 1 fans

## Questions to investigate
1. How do driver points and podiums vary across seasons?
2. How do constructor points compare over time?
3. Which countries have hosted the most Grand Prix events in the selected dataset?
4. What DNF/status patterns appear across drivers, constructors, circuits, and seasons?
5. If tyre data is available, how do observed race outcomes differ by compound?
6. If nationality data is available, how is driver representation distributed?

## Method
1. Source and inspect the data.
2. Clean and validate fields.
3. Build worksheets in Tableau.
4. Assemble interactive dashboards and a Tableau Story.
5. Check totals and document findings and limitations.

## Expected deliverables
- Documented data source
- Cleaned dataset (subject to licensing)
- Tableau workbook
- Interactive dashboard and story
- Dashboard screenshots
- Findings and limitations
