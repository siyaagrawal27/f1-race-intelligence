# Contributing

This is an educational data-visualization project.

1. Keep the original source dataset unchanged in `data/raw/` where licensing allows.
2. Put cleaned/analysis-ready data in `data/processed/`.
3. Document transformations and assumptions.
4. Verify calculations against the source data.
5. Keep screenshots in `screenshots/`.
6. Do not commit credentials, private data, or files that the dataset license prohibits redistributing.
7. Update the README when the dashboard or data source changes.
