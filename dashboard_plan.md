# Dashboard Plan

## Dashboard 1 — Executive Overview
**Purpose:** Summarize the selected seasons.
- KPI cards: events/races, drivers, constructors, podiums, DNFs, where accurately derivable.
- Season and constructor filters.
- Trend chart: points by season.

## Dashboard 2 — Driver & Constructor Performance
- Driver leaderboard by points.
- Constructor points by season.
- Comparison of selected teams, such as Red Bull Racing and Mercedes, if they appear in the data.
- Clearly label the season range and note historical scoring-system differences.

## Dashboard 3 — Strategy & Circuits
- Race outcomes by tyre compound, only if the data contains tyre information.
- Host countries ranked by number of Grand Prix events.
- Circuit participation / event count.
- Do not claim a tyre caused an outcome from simple observational charts.

## Dashboard 4 — Reliability & Podiums
- DNF counts by driver, constructor, season, and status/reason.
- Completion rate = completed starts / total starts, with the definition documented.
- Podiums by driver and constructor.
- Nationality distribution only if the source contains a nationality field.

## Tableau Story
1. Introduce the data scope and key performance trends.
2. Compare driver and constructor performance.
3. Explore circuits and tyre strategy, where supported.
4. Examine reliability and DNF patterns.
5. Summarize evidence-based observations and limitations.

## Suggested filters and interactions
- Season / year
- Driver
- Constructor
- Host country / circuit
- Tyre compound (only if available)
- Dashboard actions to filter or highlight related charts

## Validation checklist
- Reconcile totals with the source data.
- Test all filters and dashboard actions.
- Check titles, units, labels, and tooltips.
- Verify each conclusion is supported by the data.
- Include a note about missing fields and coverage limitations.
