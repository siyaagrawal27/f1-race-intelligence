# Tableau Workbook

Save the completed Tableau workbook in this folder.

## Suggested file
- `f1_race_intelligence.twbx` — packaged workbook, if file size and dataset licensing permit.
- Alternatively, save a `.twb` workbook and document how to reconnect to the data source.

## Before committing
- Check the workbook opens correctly.
- Confirm that charts and filters work.
- Remove temporary/cache files.
- Do not include private or restricted data.
- Publish to Tableau Public only if the dataset and workbook are suitable for public access.

Add the published Tableau Public URL to the root `README.md` when available.
